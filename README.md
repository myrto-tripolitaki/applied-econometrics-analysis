# Empirical Applications of Econometric Methods: Wage Determination and Transportation Policy Analysis
## Overview
This project applies econometric methods to analyze two empirical questions: wage determination and transportation demand. The analysis demonstrates the application of regression techniques, model interpretation, and statistical inference using real-world datasets.
## Project Objectives
- Estimate and interpret econometric models using real-world data.
- Study economic variables through the use of regression analysis.
- Use statistical techniques to analyze the effect of explanatory variables on economic phenomena.
## Methods
The project uses:
- Ordinary Least Squares (OLS) regression
- Hypothesis testing
- Model interpretation and diagnostics
- DiD Estimation 
- Data visualization
## Tools
- R Programming
- R Markdown
- Statistical modeling and econometric analysis
## Files
- `Empirical Applications.Rmd` — Complete R Markdown file containing code, analysis, and explanations.
- `Empirical Applications.pdf` — Final knitted report.
- `Empirical Applications.html` - Rendered version of the R Markdown document for interactive viewing in a web browser.
- `data/` — Datasets used for analysis.
## Key Skills Demonstrated
- Econometric modeling
- Data analysis and visualization
- Statistical programming in R
- Interpretation of regression results
